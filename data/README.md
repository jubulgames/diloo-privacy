# Diloo Turkish word data

These files are used by Diloo's Daily Word mode.

- `TR_Dictionary_4to6.txt`: the list of accepted guesses, one word per line.

Source: adapted from Wiktionary (https://www.wiktionary.org), the English and Turkish editions, via the Kaikki.org extracts (https://kaikki.org).
Changes: filtered to 4–6 letter base words; some words removed.
Word frequency data from the FrequencyWords project was used only to rank the words and is not included here.
